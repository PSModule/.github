# PSModule organization defaults

`PSModule/.github` is GitHub's special public repository for the PSModule
organization profile and organization-wide community health defaults. This
repository must remain public for both functions to work.

## Public organization profile

The [`profile/README.md`](profile/README.md) file provides the public PSModule
organization profile.

## Precedence and enforcement

GitHub uses the community health files in this repository when a PSModule
repository does not define its own corresponding file. A repository-local file
takes precedence and remains the enforceable PSModule surface for people,
agents, and automation.

See GitHub's guides to
[organization profiles](https://docs.github.com/en/organizations/collaborating-with-groups-in-organizations/customizing-your-organizations-profile)
and
[default community health files](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file).
