# PSModule community defaults

`PSModule/.github` is the public repository for PSModule's default community
health files. Maintainers and contributors of PSModule repositories use the
contribution guidance, code of conduct, security policy, support guidance, and
issue forms.

GitHub uses a default file when a PSModule repository has no file of that type.
For files with more than one supported location, the order is `.github`, the
repository root, then `docs`.

If a repository's `.github/ISSUE_TEMPLATE` folder contains valid issue templates
or configuration, GitHub does not use any contents of the default folder.

See [GitHub's default-file rules](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file).
