# Agent instructions

This repository is `github.com/PSModule/.github`. Read in this order:

1. [README.md](README.md) — what this repository provides and how its defaults
   are enforced.
2. [.github/CONTRIBUTING.md](.github/CONTRIBUTING.md) — how a change is made
   and reviewed.
3. `~/.msx/projects/PSModule/docs/src/docs/index.md` — the PSModule standards.
4. `~/.msx/docs/src/docs/index.md` — the inherited MSX standards.
5. `~/.msx/projects/PSModule/memory/index.md` — durable lessons from earlier
   work, read last.

Read nearest first. A local file never overrides a standard, and memory never
overrides documentation.
